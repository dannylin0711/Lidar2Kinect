# Windows side

Not started. The receiving end of Lidar2Kinect: a replacement `Kinect10.dll` (2b) and a spice2x
hook (2a) that give Dance Evolution Arcade the Kinect data the iOS app streams.

`AGENT_PROMPT.md` is the brief for the agent that builds this. `../docs/01-dea-kinect-surface.md`
is the specification.

Everything here is built as 32-bit (the game's DLL is x86), together with `../shared`.
